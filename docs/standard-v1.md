# 标准 v1（issue #97 / E6-T2）：外部顶尖做法对照方法

> 状态：**v1 草案**。指标与权重留用户裁定；在本标准生效前，不拿自家六份档案当尺子。
> 配套：可机判指标见 `docs/scorecard.md`（#96）；本文件只回答“这些指标从哪些外部做法来、对照出什么差距”。

## 四步流程

1. **调研外部顶尖档案 / 交接做法**，列可查信源候选；
2. **从顶尖做法提炼可判定指标**，每条指标能落到命令或清点项；
3. **用指标对照基础版（基线 main）与本次产物**，记录数值差距；
4. **差距写成候选 issue + 标准 v2 草案**，交用户裁定后再收紧阈值。

## 第 2 步：从外部做法提炼可判定指标

| 外部做法 | 提炼指标 | 仓内对应卡位（#96 评分卡） |
|---|---|---|
| 固定位置的持久上下文（AGENTS.md / CLAUDE.md） | 六份结构齐全、有统一入口与读法 | `coverage`（六槽位是否都有带出处条目） |
| 写法具体、可执行，不堆形容词 | 三问（身份 / 主线 / 准则）能从档案直接答出 | `answerable_questions` |
| 每条记忆可回溯、定期复核 | 条目出处可解析到 kit 内证据行；无不可追溯噪声 | `citation_accuracy` / 噪声率 |
| 一条一个概念，主线收敛 | raw 主线候选 ≤ 1，其余进历史区 | `mainline_unique` |
| 边界 / 禁止事项显式列出 | 规则槽位有持久硬规则（非任务句 / 对话句） | `rule` 槽位计数 + `rule_shape` 语义提示 |
| 简洁、按出错点迭代 | 篇幅 / 条目密度上限 | **未机判**，列入 v2 候选 |
| 定期复核、记忆不过期 | 复核状态位与回执 | #90 `review_status`（pending_review / reviewed） |

## 第 4 步：差距清单与 v2 候选（交用户裁定）

### 仍未达标 / 未机判的差距

1. **条目原子性**：一条一个概念目前靠 `case_shape` / `rule_shape` 人工抽查，没有独立计数指标；候选 issue：评分卡加“单条单概念”初判。
2. **篇幅与条目密度**：外部建议 150 行内、链接密度；仓内未计量；候选 issue：加篇幅 / 条目数上下限检查。
3. **规则形态噪声**：raw 规则仍可能混入任务句、对话指责句；语义提示不阻断结构 PASS；候选 issue：规则形态不达标计入评分卡 `rule` 槽位扣分。
4. **时间边界与平台槽位**：访谈已解析平台 / 知识库 / 时间事实，但六份暂未单列对应小节；候选 issue：身份档案补平台与时间边界段。
5. **复核节奏**：外部建议定期复核；仓内只有一次性 reviewed 状态，没有“多久未复核降级”的字段；候选 issue：review 记录带有效期。

### 标准 v2 草案待定项

- 各指标阈值是否沿用 #96 默认值（0.80 / 2-3 / 0.90 / 唯一）；
- 外部信源中哪些做法进入正式指标（层级记忆、简洁度、链接密度）；
- “本人亲历占比”这类主观指标的人工抽查比例；
- 评分卡 `--enforce-score` 是否作为交付前默认门禁。

### 边界声明

- 本文件不新增自动化判定；所有数值来自 #96 评分卡真实清点，未达标的项不写成已完成。
- 外部信源只作方法参照，不照搬其工具链；AGENTS.md 是新兴约定而非强制规范（见 agents.md 与 AgentProtocol 说明）。
- 标准 v1 生效前，`VALIDATE_OK` 只代表结构合格，不等于“好”，更不等于可交付。
