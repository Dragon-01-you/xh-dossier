# 脱敏对照表（REDACTION-MAP）

本文件逐条列出样本中“脱敏前形态 → 脱敏后片段”的替换关系，供核对脱敏是否到位。

- **两侧均已占位化**：本表不贴任何真实标识；“脱敏前形态”列只描述结构与句法特征
  （形如什么格式、哪一类词被替换），不展示真实值。完整原始材料保留在本机只读归档，未复制入库。
- 脱敏原则：替换个人身份与可定位标识，**保留**结构、emoji、时间格式、标点与句法特征。

## 占位符词表

| 占位符 | 含义 |
|---|---|
| `<chat-url>` | 会话 / 页面 URL |
| `<github-owner>/<github-repo>` | 真实 GitHub 账号名 / 仓库名 |
| `<称呼>` | 个人称呼、别名、旧昵称 |
| `<demo-title>` | 演示用代号 / 页面标题 |
| `<品牌名 X>` | 公开品牌 / 机构词典条目（节选或泛化） |

## 逐条对照

| 编号 | 适用样本集 | 脱敏前形态（抽象描述，不含真实值） | 脱敏后片段 | 规则说明 |
|---|---|---|---|---|
| R-01 | afterchat（AC-01 / 02 / 03） | 聊天平台会话链接：scheme 后接 UUID 形态路径段（域名与路径段均已隐去，不可定位） | `<chat-url>` | 会话链接整体替换，避免定位到具体会话 |
| R-02 | afterchat（AC-02） | 形如 `<github-owner>/<github-repo>` 的账号名 / 仓库名串 | `<github-owner>/<github-repo>` | 真实 GitHub 账号 / 仓库名整体替换 |
| R-03 | afterchat（AC-02） | 克隆命令中的仓库引用，账号位与仓库名同 R-02，不带真实链接 | `git clone <github-owner>/<github-repo>` | 克隆示例中的账号位与仓库名一并泛化，链接 scheme 不保留 |
| R-04 | afterchat（AC-01） | “称呼 + 的英文是什么”疑问句式 | `<称呼>的英文是什么` | 个人称呼替换；句式与疑问语气保留 |
| R-05 | afterchat（AC-03） | “演示代号 + - 图片哈希锁定复刻”标题句式 | `<demo-title> - 图片哈希锁定复刻` | 演示代号 / 页面标题替换 |
| R-06 | afterchat（AC-01） | 若干公开品牌 / 产品英文名罗列（词典类条目） | `<品牌名 A>`（后续品牌罗列节选省略） | 词典类公开条目泛化；样本只保留首类示例 |
| R-07 | semantic-cases（CD-05） | 改口句中嵌有两个旧称呼 / 别名，句式为“统一称<称呼>，就按这个吧，还是按<称呼>称呼我吧” | `统一称<称呼>，就按这个吧，还是按<称呼>称呼我吧` | 两个旧称呼 / 别名均替换为 `<称呼>`；重复改口结构保留 |
| R-08 | semantic-cases（排除项） | 语音误写、含义待确认的专名（原词不在本表展示） | 不入库：整条原话排除出案例集 | 待确认专名不做猜测性脱敏，直接排除 |

## 保留项说明

- 公开产品 / 平台名（如 Notion、IMA、闲鱼、DeepSeek 等）作为普通名词保留，
  不属于个人身份信息；如后续口径调整，再统一归一。
- 时间戳（如 `YYYY-MM-DD HH:mm:ss` 格式）按原格式保留，仅用于格式结构核对，不对应可定位身份。
- 访谈记录中的复述确认时间、轮次编号等元信息未纳入案例样本。
