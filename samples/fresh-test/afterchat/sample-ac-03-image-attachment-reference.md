### 🤖 Assistant

你提到的“锁定图片哈希值”，本质上是给图片生成一个**不可逆的数字指纹**。一旦图片内容（哪怕是一个像素）发生改变，这个哈希值就会彻底变化，从而实现对图片完整性的精准校验。目前网页上最常用、也最标准的方法，是借助浏览器原生的 **Web Crypto API** 来计算 **SHA-256** 哈希值。

具体来说，它包含两个步骤：

1. **生成唯一指纹**：利用 Web Crypto API 读取图片的二进制数据，并计算出一个 256 位的哈希字符串。
2. **锁定并校验**：将这个哈希值“锁定”在代码中。当图片加载时，前端会重新计算一次哈希值，并与锁定值进行比对。如果两者一致，说明图片是原版；如果被篡改，哈希值就会改变，从而触发安全机制。
