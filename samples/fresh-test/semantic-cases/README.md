# 语义正反例样本集（issue #63 归档）

## 用途

本目录存放从本机真实访谈记录中挑选、并经过脱敏的用户原话案例，用于对照
issue #63「抽象偏好句与长句 / 方言 / 代码句的正反例样本集」所列出的未覆盖边界：

- 抽象偏好句：有 outcome 词但缺具体场景 / 损失后果；
- 长句 / 长段：篇幅长、要点密集，断句与抽取易出错；
- 方言 / 口语 / 语音痕迹：语气词、改口、重复、语音误写；
- 中英 / 产品名 / 代码混句：混排词、公开产品名、技术名词；
- 多轮打断 / 纠偏句：对系统流程的意见，需与自身画像陈述区分；
- 正例 / 反例锚点：用户明确给出的正面做法与反面做法。

## 分组定义

- **正例**：带具体事件 / 场景 / 代价，可直接支撑画像判断；
- **反例**：他人材料、提问句、无效吐槽、过度依赖等不应进正向候选的内容；
- **边界**：有偏好或 outcome 词，但缺具体场景 / 后果，或归属存疑，需人工裁定。
