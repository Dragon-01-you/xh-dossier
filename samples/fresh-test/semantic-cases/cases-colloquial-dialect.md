# 案例集 CD · 方言 / 口语 / 语音痕迹（issue #63 归档）

> **用途**：对照 issue #63「方言、口语、语音输入痕迹的规则 / 正反例判据未覆盖」。
> 本组收录带语气词、口语句式、改口打断与语音输入痕迹的原话，用于核对
> 归一化时是否保留真实语义、是否把口语虚词误当要点。
>
> **来源**：本机一次真实运行留下的访谈记录文件（用户原话逐条记录）。来源只做相对描述，
> 不记录用户名；原话已按 `../REDACTION-MAP.md` 脱敏。
>
> **边界声明**：本案例集是归档参考材料，**不混进未来正式测试，不进 pytest、不进 CI**。
