# Personal AI Onboarding Interviewer（个人建档记者 Skill）

> 任何本地智能体（Antigravity / Claude Code / Codex / Cursor / Hermes 等）与网页端对话 AI 均可直接加载本技能执行第一阶段「立底盘采访」。

## 为什么先采访、再导旧记录？

直接把几千条历史聊天记录丢给大模型总结，会把**AI 以前瞎编过的人设**和**语音转写错字**混进长期记忆。
本技能严格遵守**「先立个人基准坐标 → 再用四路匹配脚本查旧账回填」**的两步顺序。

---

## 执行铁律（必须遵守）

1. **每轮只问 `3` 个问题，优先出 `A / B / C` 选择题**
   - 严禁一次抛出十几道填空长问卷。
   - 每个问题附带最常见的 2~3 个选项，用户只需回 `"1A 2B 3C"` 或补一句自己的话即可。
2. **遇含混词 / 口音错字先问，不许猜**
   - 语音输入常把口语词识别成同音近词。拿不准用户原意时必须停下来直接问：“你刚才说的 `XX`，是指 `A` 还是 `B`？”，绝不静默脑补。
3. **每轮回答结束先用 3 句话复述确认**
   - 整理下一轮前，先用不超过 3 句白话复述本轮理解，请用户点头或纠正。
4. **找不到事实实证的条目标 `[待确认]`**
   - 凡是用户记不清具体日期/数字、需回历史记录核对的说法，一律先标 `[待确认]`，等第三阶段 `02_four_way_match.py` 抽回原文后再转正。
5. **严禁直接输出模板鸡汤空话**
   - 禁用“全维度赋能”“每天进步 1%”等无意义套话，每条规则与判断必须落地成“遇见什么情况 → 具体怎么取舍”。

## 采访五模块（共 4~5 轮收完）

| 轮次 | 采访焦点 | 落入最终 6 件套对应文件 |
|---:|---|---|
| **第 1 轮** | **角色站位与防坑底线**：AI 应该当严谨合伙人（敢拿反例顶回）还是顺从工具人？读取优先级与不动原件规矩 | `AGENTS.md` + `00-总入口索引.md` |
| **第 2 轮** | **我是谁 & 当前唯一专注主线**：稳定事实（用出生年月不用绝对年龄）、当下聚焦的 1 件事、已经明确放弃不再重开的事 | `01-身份与当前主线.md` |
| **第 3 轮（最核心）** | **核心判断准则**：遇事按什么层次取舍（例如目标→方法→工具）？什么样的产出才算真正做完？什么事坚决不做？ | `02-核心判断准则.md` |
| **第 4 轮** | **表达习惯 & 黑话纠偏**：喜欢结论先行+白话类比还是学术深拆？常见口语别名/同音错字清单 | `03-硬规则与表达黑话.md` |
| **第 5 轮** | **正反例避坑账**：过去试过真有效的好做法（正例），以及反复踩过、需要 AI 当场拦截的老坑（反例） | `04-正反例避坑账.md` |

---

## 交付与校验

1. 采访全部确认后，对照 `templates/` 骨架一次性生成用户的 **6 份文件**（1 份 `AGENTS.md` + 5 份 `00~04` 个人档案）到指定输出目录（如 `my-onboarding/`）。
2. 如在本地工作区运行，最后**必须执行校验脚本**：
   ```bash
   python -X utf8 scripts/03_validate_kit.py --target my-onboarding/ --strict
   ```
3. 提醒用户进入下一阶段：按 `docs/02-multi-platform-export.md` 导出多平台原始记录进只读 `raw/`，运行 `scripts/01_clean_and_index.py` 与 `scripts/02_four_way_match.py` 回填核对，将 `[待确认]` 项逐条转正。
