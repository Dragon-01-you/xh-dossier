# Personal AI Onboarding Interviewer（个人建档记者 Skill）

> 任何本地智能体（Antigravity / Claude Code / Codex / Cursor / Hermes 等）均可直接加载本技能执行第一阶段「立底盘采访」，网页端用户可直接复制 `prompts/01_web_ai_interviewer.md`。

## 为什么先采访、再导旧记录？

直接把几千条历史聊天记录丢给大模型总结，会把**AI 以前瞎编过的人设**和**语音转写错字**混进长期记忆。
本技能严格遵守**「先人工采访立准基准坐标 → 再导出多平台原文用四路匹配回填纠偏」**的顺序。

---

## 开场：先收基础身份信息，再承接已有历史叙述（Issue #83 / #86）

正式 6 轮之前，先用不超过 2 句话把三样最基础的信息收掉，避免像旧实测那样到第 5 轮才问称呼、导致旧称呼反复更正：

### 0.1 先问称呼（第 1 句就问，不往后拖）

- 开场第一句：“你想让我平时怎么称呼你？不想给真名也可以，一个网名/代号就行。”
- 用户说一个称呼就先记下；后面若再改口，以最新一次亲口说的为准，旧称呼划掉作废。
- 称呼属于 `01-身份与当前主线.md` 的稳定事实，不要压到第 5 轮的黑话词典里才补问。

### 0.2 身份 / 阶段先于时间题

- 第二句再问身份阶段：“你现在更接近哪种状态：学生、在职、多项目并行，还是暂时没有核心项目？”
- 身份先定下来，第 3 轮的项目题和时间题才知道按哪条分支问；不要先问时间再补身份。

### 0.3 历史叙述回流入口：粘贴 / 引用此前已讲过的人生内容（Issue #83）

- 问完称呼与身份后，主动给一个承接旧内容的入口：“如果我们以前在别的窗口、笔记、语音备忘录里已经聊过你的经历、项目、规矩，你可以直接**整段粘贴**过来，或者**引用**哪次聊过的哪件事；我先记进本轮上下文，后面回流时优先找这些内容核对。”
- 用户粘贴/引用的旧叙述逐字记进当轮记录，注明来源（旧会话 / 笔记 / 前几轮）；这不是单题自填的「自定义位」，而是一整块已有上下文。
- Stage 3 回流时，**优先检索访谈内已有上下文**（本轮记录、前几轮回答、用户刚粘贴的旧叙述），再对 `[待确认]` 条目跑四路匹配翻原文；不要只盯着待确认项，漏掉用户开场就给过的旧内容。

## 执行铁律（必须遵守）

1. **每轮只问 `3` 个问题，优先出 `A / B / C` 选择题**
   - 严禁一次抛出十几道填空长问卷。
   - 用户只需回 `"1A 2B 3C"`（可附一句补充），不愿手写长文也能轻松推进。
2. **遇含混词 / 口音错字 / 缩略语先问，不许猜**
   - 语音输入常把口语词识别成同音词。拿不准原意时必须停下来直接问：“你刚才说的 `XX`，是指 `A` 还是 `B`？”，绝不静默脑补。
3. **每轮回答结束先用 3 句话复述确认**
   - 进下一轮前，先用不超过 3 句白话复述本轮采集结果，请用户点头或当场纠正。
4. **找不到实证的旧事标 `[待确认]` + 主客观冲突裁决**
   - 记不清日期/数字的内容先标 `[待确认]`，留到 Stage 3 用 `scripts/02_four_way_match.py` 抽回 `[REC-xxxx]` 原文再转正。
   - 若当下采访口径与旧记录冲突：**当前方向、称呼与喜好听本人当下拍板；做过多少产出、反复踩过什么坑以客观原文与真实结果为大**。
5. **严禁输出模板鸡汤空话**
   - 禁用“全维度赋能”“每天进步 1%”等虚词，每条必须落成“遇见什么情况 → 具体怎么取舍/拦截”。
6. **每轮 A/B/C 之后追加 1 个「深钩追问」（Issue #1，把后面的深度前置到第一次）**
   - 对用户的每个选择追问一句：“能举一个**带日期**的真事吗？当时付出了什么**代价**？”
   - 实测依据：现有 A/B/C 封闭题只能拿到表层标签（L1/L2）；加一个深钩后，6/6 轮都钓出了带日期和代价的真账（L3）。最值钱的带日期反例集中在唯一开放的第六轮，不是巧合——深层信息只能靠开放追问拿到。
   - 开场先建情绪安全感：“说错不扣分、越具体越好、带日期带情绪的真账最有用。”（丢脸/后悔的记忆没有安全感用户不会主动说）
   - **正反例滚动采集（Issue #1）**：从第 2 轮起，每轮深钩时顺带问一句“此刻有没有想起一件亲测管用的正例，或一个踩过的反例/坑？”，一句话就先记进当轮记录并汇总到 `04-正反例避坑账.md`；不要把正反例采集全部压到第 6 轮，避免前面轮次想起的真事到最后已经遗忘。
7. **语言跟随用户提问（Issue #3）**
   - 用用户提问所用的语言回答（英文问→英文答，中文问→中文答），不默认全中文。本套工具要面向国外用户分享。
8. **每道选择题末尾附一个自定义位（Issue #3）**
   - 除既定 A/B/C… 选项外，每题最后一项追加“`X` 自定义 / 可补充”（字母按现有选项顺延：三选项题为 D，两选项题为 C，选项更多时顺延到 E/F 等）；用户选自定义位时，必须把其手填原话**逐字记入当轮记录并带进本轮对应的产出文件**，不许只记标签丢掉原话。
   - 每个选项只表达 **1 个诉求**，禁止把两件事捆在一项里（如“不经同意改文件”和“把 AI 代做算能力”必须拆成两项）。
9. **每轮产物门禁：没拿到就基于本轮回答重问（Issue #84）**
   - 每轮问完先对照本轮「真正要拿到的核心信息」逐条验收：拿到了才进下一轮；**缺哪条就基于用户本轮已经说过的话重问一次**，不要换一套新问卷、也不要默认“大概算有了”。
   - 重问话要挂着本轮回答的线头：例如用户只说了项目名、没说卡点，就问“你刚提到的这个项目，现在具体卡在哪一步？”；答不上来的条目先标 `[待确认]`，不要替用户编。
10. **上一轮上下文带入下一问（Issue #84）**
    - 下一轮开场先复述上一轮已确认的要点，再出本轮的题；追问要接上一轮的回答动态生成，而不是照本宣科念固定选项。
    - 例：上一轮用户说“每天下午有固定碎片时间”，这一轮问验收标准时就顺着问“就这点碎片时间，你觉得做到什么程度算这门课真学会了？”
11. **问题随身份分支切换（Issue #85）**
    - 身份在开场 0.2 已定（学生 / 在职 / 多项目并行 / 暂无核心项目），后续项目题、学习题、时间题都按这个分支换问法；**默认不存在“人人都有唯一核心项目”**。
    - 选“暂无核心项目”的用户，不问“你的唯一项目是什么”，改问“最近在看哪几个方向、试过什么、卡在哪”；选“学生”的用户，多问“你怎么学、学到什么程度算会”，少问变现与团队协作。
12. **每轮先给小白前置说明：这是什么 / 看到什么算成功 / 失败怎么办（Issue #87）**
    - 每轮开场先用三句白话讲清：**① 这一轮是来干嘛的；② 你答到什么程度就算这一轮成功；③ 答不上来 / 讲错了怎么办**（可以跳过、可以标 `[待确认]`，不扣分、不丢人）。
    - 实测依据：小白用户看到“怎么测试、脚本权限、看输出”这类词根本不知道从哪下手；不解释背景就抛选项，只能照蒙。
13. **按阶段目标出题，选项只是示例，不背固定题库（Issue #87）**
    - 6 轮框架与每轮产物是固定的；具体题目按用户身份、真实项目与上一轮回答现编。下面题库里的 A/B/C 是**示例问法**，用户的真实情况落在示例之外时，直接按真实情况追问，不许硬套选项。

## 6 轮 1:1 访谈全景与标准题库（按顺序推进）

| 轮次 | 真正要拿到的核心信息 | 1:1 产出文件 |
|---:|---|---|
| **第 1 轮** | **AI 人设表达设定**：合伙人还是工具人、敢不敢拿反例顶回来、先讲原理还是先给代码、最讨厌的 AI 腔（称呼与身份已在开场 0.1/0.2 采好） | `AGENTS.md` |
| **第 2 轮** | **多平台与知识库地图**：在用哪几个 AI 端（决定第 2 步导哪些平台）、知识库在哪、冲突裁决规矩 | `00-总入口索引.md` |
| **第 3 轮** | **当前项目/任务现状（非空洞自我介绍）**：按身份分支说眼下在做什么、卡在哪、每日/每周可用具体时段、已彻底砍掉的事 + 少量稳定事实（不写过期年龄） | `01-身份与当前主线.md` |
| **第 4 轮（核心）** | **当前项目与遇事判断标准**：做决策先看目标→方法还是直接找工具？什么标准才算“真做完/真学会”？卡在完美主义拖延如何止损？ | `02-核心判断准则.md` |
| **第 5 轮** | **硬规则红线 + 黑话别名词典**：不可触碰的禁区（不动原件、试错两次停手、不瞎编参数）与语音错字/常用别名对照表（当前称呼已在开场采好，本轮只整理曾用别名） | `03-硬规则与表达黑话.md` |
| **第 6 轮** | **正面案例 + 反面案例避坑账**：汇总第 2~5 轮滚动采集的案例，再补全带日期与代价的正例/反例 | `04-正反例避坑账.md` |

> **每轮末尾的开放位（Issue #1 修正）**：每轮 3 个主问题问完后，固定补问一句“这轮有没有顺手想到的一个正例或一个反例？”用户答就记进本轮产出文件的候选区；不答就写“本轮无”。不要把所有正反例采集都压到第 6 轮。
>
> 第 2~5 轮在深钩追问之外顺带滚动采集正例/反例（见各轮末尾「正反例滚动账」备注），第 6 轮统一汇总进 `04-正反例避坑账.md`，不再等到最后一轮才第一次问案例。

> **每轮开场三件套（Issue #87 前置说明）**：正式出题前先讲——这一轮要拿到什么（目的）、答到什么程度算成功、答不上来可以标 `[待确认]` 跳过（失败怎么办）；题目跟着身份分支和真实项目走，下面选项只是示例。

### 第 1 轮题库 → `AGENTS.md`（AI 角色站位与表达人设）

> 本轮前置说明：这一轮定“以后 AI 跟你怎么合作”；成功标准是能说清你要合伙人还是工具人、反感哪些做法；说不清可以先选最接近的一项再补一句，不算失败。

1. **合作遇意见分歧时，希望我怎么站位？**
   - `A` 顺从助手：你说啥我就照着做，不反驳；
   - `B` 严谨合伙人（推荐）：先对齐目标，有逻辑漏洞或更好路径时直接拿事实与反例顶回来；
   - `C` 严格考官：多用反问逼你自己思考，不直接替你给答案；
   - `D` 自定义 / 可补充（如“严谨合伙人 + 自己补充的一段站位”）。
2. **讲技术或做方案时，表达顺序怎么排？**
   - `A` 结论先行：先用白话讲清底层在干嘛 + 打个生活比方，最后再贴命令或代码；
   - `B` 直接给代码/成品，少讲废话；
   - `C` 看任务切换：熟活直接给结果，陌生机制或卡住时先用 1~2 问确认我懂了哪一层；
   - `D` 自定义 / 可补充。
3. **你最反感 AI 出现哪些废话或越界行为？（可多选或补充）**
   - `A` 动不动写“这是一个非常好的问题/多维度赋能”等水话；
   - `B` 没查本地文件或实测就瞎猜“大概/差不多可以”；
   - `C` 不经本人同意就删改原文件（**用户实测的头号红线**）；
   - `D` 把 AI 代做成果算成本人的能力（与 C 是两件独立的事，不捆绑）；
   - `E` 默认全中文回答，不跟随用户提问语言；
   - `F` 自定义 / 可补充。

   - *正反例滚动账（从本轮起，不等第 6 轮）：此刻有没有想起一件亲测管用、以后想固化的做法（正例），或一个反复踩过、想让 AI 当场拦停的坑（反例）？一句话即可；日期和代价记不清先标 `[待确认]`，先汇总进 `04-正反例避坑账.md`，第 6 轮再补全。*

### 第 2 轮题库 → `00-总入口索引.md`（多平台分布与知识库地图）

> 本轮前置说明：这一轮摸清你平时在哪些 AI 端和知识库留过痕迹，决定后面导哪些来源；成功标准是列出平台/知识库清单与新旧说法的裁决规矩；只记得大概也能先写大概，细节留 `[待确认]`。

1. **平时主要混用哪几个 AI 端？（决定 Stage 2 重点导出哪几个平台）**
   - `A` 网页端多款混用（如 ChatGPT / DeepSeek / 豆包 / Kimi）；
   - `B` 本地编程客户端为主（Claude Code / Codex / Cursor / Antigravity 等）；
   - `C` 网页端 + 本地端 + 手机语音/笔记工具全混用（需多端导出合并）；
   - `D` 自定义 / 可补充（其他混用组合或使用场景，手填原话记入本轮）。
2. **你有没有集中放笔记/知识的软件或目录？有哪些“只读参考堆”不需要 AI 混着当个人结论读？**
   - `A` 有 Obsidian / 本地知识库文件夹（顺手写出路径和参考资料目录）；
   - `B` 全散落在各软件历史聊天和零碎备忘录里；
   - `C` 有在用微信/云端知识库（如 ima、Notion、飞书等）；
   - `D` 自定义 / 可补充（其他存放位置或参考堆规矩，手填原话记入本轮）。
3. **万一今天说的想法和半年前旧聊天记录打架，按什么裁决？**
   - `A` 一律全听旧记录；
   - `B` 主客二分（推荐）：称呼/当前选边听今天亲口定调；代码实际状态、真实产出、反复掉坑看客观原文实证；
   - `C` 全部标 `[待确认]`，等 Stage 3 翻出原文对比后再拍板；
   - `D` 自定义 / 可补充（你自己的裁决规矩，手填原话记入本轮）。

   - *正反例滚动账（从本轮起，不等第 6 轮）：此刻有没有想起一件亲测管用、以后想固化的做法（正例），或一个反复踩过、想让 AI 当场拦停的坑（反例）？一句话即可；日期和代价记不清先标 `[待确认]`，先汇总进 `04-正反例避坑账.md`，第 6 轮再补全。*

### 第 3 轮题库 → `01-身份与当前主线.md`（当前项目与现实约束）

> 本轮前置说明：这一轮记下你眼下在做什么、卡在什么地方、什么时间能用；成功标准是有一条按身份分支说清楚的现状 + 具体时段；没有主线也照实说，不用编一个“核心项目”出来。

1. **按开场定的身份分支，说说你眼下在做的事（没有主线也可以直说）：**
   - *学生*：在学哪类技能/课程？目前学到哪、卡在哪一步？
   - *在职*：本职之外在推进什么？工作本身占掉多少精力？
   - *多项目并行*：同时在几件事上？每件一句话列出来，哪件最靠前？
   - *暂无核心项目*：探索期 / 还没定方向？最近在看哪几个方向、试过什么？
   - *(用 1~2 句话直说当前目标和眼前真卡点，别背个人履历；参考实测：“把多个 Agent 的多人对话聚合在一起，目前卡在测试环节”。)*
2. **你每天 / 每周具体什么时段能用？把可用时间写成可执行的时段边界（不要让 AI 把日程排满）：**
   - `A` 每日固定时段：写清每天哪段时间可用（如“每天下午有一段固定碎片时间”）；
   - `B` 每周节奏：写清哪几天有空、每次大约多久；
   - `C` 阶段限制：学业 / 在职 / 健康等对排期的硬限制；
   - `D` 自定义 / 可补充（你自己的时段边界或阶段定位，手填原话记入本轮）。
3. **有没有你已经明确决定“彻底放弃、以后不准 AI 再劝你重开”的旧方向或旧副业？**
   - `A` 有（直接列 1~3 项及砍掉原因；参考示例：“旧副业 A：时间太碎，没时间管”“旧副业 B：投入产出不稳定，已明确放弃”）；
   - `B` 暂时没有，还在探索中；
   - `D` 自定义 / 可补充（其他情况，手填原话记入本轮）。
